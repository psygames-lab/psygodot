# Temple Runner PRD

## Goal

Create a playable temple/jungle runner that demonstrates PsyGodot through real gameplay. The player experience comes first; psych instrumentation is a background layer.

## Player Experience

- Title screen with start flow.
- Three-lane automatic running.
- Lane change, jump, and slide controls.
- Procedural temple corridor with jungle/ruin identity.
- Obstacles, hazards, gaps, gates, and collectible gems.
- Score, distance, combo, hearts, restart, and game-over flow.
- Audio and visual feedback for success, mistakes, and state changes.

## Instrumentation Experience

Telemetry records meaningful runner moments without turning them into visible trials. Measurement opportunities are embedded in real obstacles, rewards, hazards, and route choices.

## Non-Goals

- Reversal-learning task UI.
- Trial-by-trial screen flow.
- External hardware timing guarantees.
- Copied Temple Run branding or assets.
